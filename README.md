# GoIT Advanced JavaScript Homework 01

Vite project for Theme 2 homework:

- `1-gallery.html`: dynamically rendered image gallery with SimpleLightbox.
- `2-form.html`: feedback form with localStorage persistence and validation.

## Run locally

```sh
npm install
npm run dev
```

Create the production build with `npm run build`. GitHub Actions deploys the
build to GitHub Pages from the `main` branch.
